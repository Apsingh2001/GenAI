# Python Functions Assignment

This project contains seven small Python exercises covering functions, recursion, lambda expressions, `map()`, `filter()`, and loops.

## Tasks

- **Task 1:** Calculate a price after discount, with a default 5% discount and a 60% maximum discount.
- **Task 2:** Calculate factorials recursively, including handling negative values.
- **Task 3:** Calculate prices after adding 18% GST with a lambda function.
- **Task 4:** Apply GST to a list of prices using `map()`.
- **Task 5:** Separate prices above 500 from prices at or below 500 using `filter()`.
- **Task 6:** Apply a 10% discount and filter discounted prices above 300.
- **Task 7:** Use functions and a loop to manage prices through an interactive menu.

## Requirements

- Python 3.x
- No external packages are required.

## Running the Tasks

From this folder, run an individual task with:

```powershell
python Task1.py
```

Replace `Task1.py` with `Task2.py` through `Task7.py` as needed.

`Task7.py` is interactive. Select an option from its menu, enter prices when prompted, and choose `q` to quit.
