# File Handling Assignment

This project demonstrates basic Python file handling and data processing.

## Tasks

- `Task1.py`: Creates `sales_data.txt` and writes the initial sales values.
- `Task2.py`: Reads `sales_data.txt` using `read()`, `readline()`, and `readlines()`.
- `Task3.py`: Appends new sales values and displays the updated file.
- `Task4.py`: Calculates total, highest, lowest, and average sales.
- `Task5.py`: Collects three products and prices, then writes them to `products.txt`.
- `Task6.py`: Safely checks whether a requested file exists before reading it.
- `Task7.py`: Applies a user-supplied discount and creates `discount_report.txt`.

## How to Run

Run the scripts from this project directory with Python:

```text
python Task1.py
python Task2.py
python Task3.py
python Task4.py
python Task5.py
python Task6.py
python Task7.py
```

`Task5.py`, `Task6.py`, and `Task7.py` ask for user input.

## Generated Files

- `sales_data.txt`: Sales values, one per line.
- `products.txt`: Product names and prices in `ProductName | Price` format.
- `discount_report.txt`: Original and discounted prices with a summary.

## Requirements

- Python 3
- No external libraries are required.
