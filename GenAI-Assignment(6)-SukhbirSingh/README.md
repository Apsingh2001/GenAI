# GenAI Assignment

This project contains five Python programs demonstrating exception handling.

## Tasks

- **Task 1 - Safe Division Utility**: Divides two user-provided numbers and handles invalid input and division by zero.
- **Task 2 - Bill Calculator**: Calculates a bill while skipping non-numeric and negative prices.
- **Task 3 - Age Validator**: Validates that an age is between 1 and 120.
- **Task 4 - File Reader**: Reads and displays the first three lines of a file while handling missing or inaccessible files.
- **Task 5 - Safe Shopping Cart**: Accepts item prices until the user enters `q`, then displays the total items and bill.

## Requirements

- Python 3.x

## How to Run

Run any task from PowerShell or a terminal:

```powershell
python Task1.py
python Task2.py
python Task3.py
python Task4.py
python Task5.py
```

Tasks that require user input will prompt for values while running.
