## How to Run

Run each task from the project folder with Python:

```bash
python Task1.py
python Task2.py
python Task3.py
python Task4.py
```

## File-to-Task Mapping

- `Task1.py` runs Task 1: Product Collections (Lists & Tuples).
- `Task2.py` runs Task 2: Categories (Sets).
- `Task3.py` runs Task 3: Product Pricing (Dictionaries).
- `Task4.py` runs Task 4: Combined Operations.
