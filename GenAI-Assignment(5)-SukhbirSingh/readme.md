# Modules Assignment

A simple Python assignment demonstrating modules, packages, imports, and function calls.

## Structure

- `modules_assignment/math_utils.py`
  - `add(a, b)`
  - `subtract(a, b)`
  - `square(n)`
- `modules_assignment/string_utils.py`
  - `capitalize_words(text)`
  - `reverse_string(text)`
  - `word_count(text)`
- `shop_package/discount.py`
  - `apply_discount(price, percent)`
  - `flat_discount(price)`
- `shop_package/billing.py`
  - `calculate_total(prices)`
  - `apply_tax(amount)`
- `modules_assignment/main.py`: imports and tests all functions.

## Run

From the project root, run:

```bash
python -m modules_assignment.main
```
