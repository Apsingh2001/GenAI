# NumPy Assignment

This project contains practical NumPy exercises covering array creation, mathematical operations, statistics, percentiles, sorting, and sales analysis.

## Requirements

- Python 3.x
- NumPy

Install NumPy with:

```powershell
pip install numpy
```

## Tasks

- `Task1.py`: Create 1D and 2D NumPy arrays and display their shapes and data types.
- `Task2.py`: Additional NumPy assignment task.
- `Task3.py`: Calculate square roots, exponentials, logarithms, sums, and cumulative sums.
- `Task4.py`: Perform row-wise and column-wise aggregation operations.
- `Task5.py`: Calculate statistical values for student marks.
- `Task6.py`: Sort marks, calculate percentiles, and count above-average scores.
- `Task7.py`: Analyze weekly sales data.

## Running the Tasks

From the project folder, run any task with:

```powershell
python Task1.py
python Task2.py
python Task3.py
python Task4.py
python Task5.py
python Task6.py
python Task7.py
```
