# OOP Product Exercises

This project contains seven standalone Python exercises demonstrating core object-oriented programming concepts.

## Tasks

- **Task 1:** Basic `Product` class and object creation
- **Task 2:** Constructor and encapsulation with a guarded price setter
- **Task 3:** Single-level inheritance with `ElectronicProduct`
- **Task 4:** Polymorphism with `Laptop` and `Mobile`
- **Task 5:** Abstraction using the `Payment` abstract base class
- **Task 6:** Magic methods: `__str__` and `__add__`
- **Task 7:** OOP inventory system using `Product`, `Inventory`, and `Store`

## Requirements

- Python 3.x
- No external packages are required.

## Running the Exercises

Run any task from the project directory:

```bash
python Task1.py
python Task2.py
python Task3.py
python Task4.py
python Task5.py
python Task6.py
python Task7.py
```

`Task7.py` prompts for the name, price, and category of three products before displaying the inventory summary and combined price of two products.
