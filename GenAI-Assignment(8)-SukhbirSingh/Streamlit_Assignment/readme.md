# Streamlit Assignment

This folder contains four simple Streamlit applications demonstrating common UI components and interactions.

## Applications

### 1. Basic Streamlit App

File: `app_basic.py`

- Displays a welcome title
- Accepts a user's name
- Displays a personalized greeting

Run with:

```bash
streamlit run app_basic.py
```

### 2. Price Calculator

File: `app_discount.py`

- Accepts a product price
- Selects a discount from 0% to 50%
- Calculates and displays the final price
- Shows a before-and-after comparison table

Run with:

```bash
streamlit run app_discount.py
```

### 3. Product Form

File: `app_product_form.py`

- Accepts product details in the sidebar
- Provides product category options
- Displays the submitted product information

Run with:

```bash
streamlit run app_product_form.py
```

### 4. Mini Dashboard

File: `app_dashboard.py`

- Allows users to select a month
- Displays the selected month's sales
- Shows monthly sales in a bar chart

Run with:

```bash
streamlit run app_dashboard.py
```

## Requirements

- Python 3.8 or newer
- Streamlit

Install Streamlit with:

```bash
pip install streamlit
```

## Running the Apps

Open a terminal in this folder and run any application using its corresponding command above. Streamlit will provide a local URL in the terminal.
